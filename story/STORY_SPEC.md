# 十日终焉·知识觉醒系统 - 剧情模块项目规格书
(v3.0 剧情深度版)

## 一、世界观设定

### 1.1 核心概念
- **觉醒者**：你，意外进入「终焉之地」的学习空间
- **终焉之地**：模拟学习环境，由「天龙」创造的牢笼
- **目标**：通过知识觉醒，成为超越天龙的存在
- **轮回**：每十日重置一次，但觉醒的记忆会部分保留

### 1.2 核心要素映射
| 游戏概念 | 知识概念 |
|---------|--------|
| 每座城 | 每个知识库 |
| 城中的「道」 | 学习目标 |
| 十日轮回 | 学习周期 |
| 十二生肖 | 知识守护者 |
| 回响 | 觉醒的学习能力 |

### 1.3 场所架构

│                     终焉之地 · 学习空间                        │

│   │ (初始降临)   │    │ (学习挑战)   │    │  (天级挑战)  │     │

## 二、剧情系统

### 2.1 主线剧情（十日轮回）

| 日数 | 标题 | 剧情概述 | 关键选择点 |
|------|------|---------|-----------|
| 第1日 | **「降临」** | 醒来在面试房间，理解规则，选择初始生肖 | 初始阵营倾向 |
| 第2日 | **「初试」** | 击败人级生肖，收集第一波「道」，遇到其他觉醒者 | 结识NPC |
| 第3日 | **「裂痕」** | 触发「回响」能力初醒，发现轮回异常 | 选择信任谁 |
| 第4日 | **「分岔」** | 势力招揽or独立，命运第一次分叉 | **重大分支点** |
| 第5日 | **「攻城」** | 挑战地级生肖，发现知识城池的秘密 | 攻城策略 |
| 第6日 | **「暗流」** | 势力冲突升级，发现天龙计划的线索 | 势力站队 |
| 第7日 | **「背叛」** | 阵营抉择，可能是盟友的背叛 | **重大分支点** |
| 第8日 | **「天位」** | 挑战天级生肖，接近真相 | 战斗选择 |
| 第9日 | **「抉择」** | 最终路线确定，无法回头 | **不可逆分支** |
| 第10日 | **「终焉」** | 挑战天龙，根据路线走向不同结局 | 结局判定 |

### 2.2 多重结局路线

#### 路线A：「反抗者之路」
```
条件：与天龙阵营彻底决裂 + 累计击败3位天级生肖
最终挑战：与天龙一对一知识对决
结局：胜利→逃离终焉之地，成为新的「引路人」
      失败→强制轮回，保留部分记忆
```

#### 路线B：「新天龙之路」
```
条件：累计收集500「道」+ 击败天龙
最终挑战：接受天龙的力量传承
结局：成为新任天龙，维持轮回秩序（或暗中改变规则）
```

#### 路线C：「破壁者之路」
```
条件：触发所有「回响」觉醒 + 找到隐藏知识库「道外之道」
最终挑战：破解终焉之地的底层逻辑
结局：打破轮回规则，创造新的学习空间
```

#### 路线D：「共犯之路」
```
条件：与至少2个势力建立深度同盟
最终挑战：势力联合挑战天龙
结局：根据同盟势力比例，获得不同层级的自由度
      - 天堂口主导：集体逃离
      - 极道主导：暴力打破规则
      - 猫主导：隐秘逃离
```

#### 路线E：「轮回者之路」
```
条件：未能在第10日击败天龙
结局：进入下一轮回，但保留「道」和部分「回响」
      累计3次轮回失败→触发隐藏结局「觉醒者的宿命」
```

#### 路线F：「遗忘者之路」（隐藏结局）
```
条件：主动放弃所有「道」和「回响」
触发条件：第9日选择放弃
结局：成为终焉之地的「NPC」，永远帮助后来的觉醒者
```

### 2.3 隐藏剧情线

#### 「天龙之影」线
- **触发**：第6日后，累计获得200「道」
- **内容**：发现天龙曾是第一个觉醒者，他的目的是...
- **分支**：帮助天龙 / 阻止天龙 / 利用天龙

#### 「前任觉醒者」线
- **触发**：遇到特定NPC「轮回者」韩片羽
- **内容**：她是第27次轮回的幸存者，掌握关键信息
- **道具奖励**：「记忆碎片」可查看任意一天的完整记忆

#### 「城之心」线
- **触发**：击败某知识库的所有生肖守护者
- **内容**：知识城池的核心秘密，解锁隐藏知识区
- **奖励**：获得「道外之道」知识库访问权

#### 「时间悖论」线
- **触发**：使用「时间回溯」回响超过10次
- **内容**：发现轮回中时间线的异常
- **影响**：可能触发路线C的前置条件

### 2.4 记忆碎片系统

轮回中，部分关键场景会以「记忆碎片」形式保留：

| 碎片类型 | 保留内容 | 用途 |
|---------|---------|------|
| 关键对话 | NPC的重要对话 | 解锁隐藏选项 |
| 战斗记忆 | 失败/胜利的战斗 | 获得战斗经验加成 |
| 选择记忆 | 所有分支选择 | 影响后续剧情走向 |
| 隐藏发现 | 探索到的秘密 | 解锁隐藏剧情 |

**记忆碎片使用**：
- 消耗3个同类型碎片 → 回溯查看当时的完整场景
- 消耗5个碎片 → 改变一个不可逆选择的部分结果
- 消耗全部碎片 → 触发「全视者」成就，解锁路线C

### 2.5 蝴蝶效应系统

某些选择会产生长期影响：

| 选择 | 短期影响 | 长期影响（第7日+） |
|------|---------|------------------|
| 帮助天堂口成员 | 好感+10 | 解锁天堂口核心剧情 |
| 拒绝所有势力 | 独立路线 | 猫势力会秘密接触 |
| 告诉NPC你的回响 | 信任建立 | 可能被泄露给其他势力 |
| 抢夺他人「道」 | 快速积累 | 貔貅势力会敌视你 |
| 放过失败的对手 | 潜在盟友 | 可能获得关键情报 |

## 三、势力系统

### 3.1 四大势力

| 势力 | 理念 | 领袖 | 总部位置 |
|------|------|------|---------|
| **天堂口** | 团结协作，共同逃离 | 楚天秋（天级天龙） | 中央广场 |
| **极道** | 以力量打破规则 | 燕知春 | 地下擂台 |
| **貔貅** | 智慧敛财，利益至上 | 钱 Meck | 市场区 |
| **猫** | 暗中行动，积蓄力量 | 陈俊南（回响者） | 阴影区 |

### 3.2 势力关系矩阵

```
              天堂口    极道    貔貅    猫
天使口        -        合作    竞争    暗中结盟
极道          合作      -      敌对    未知
貔貅          竞争      敌对    -      交易
猫            暗中结盟   未知    交易   -
```

### 3.3 势力详细设定

#### 天堂口（Heaven's Gate）
```
加入条件：
- 学习进度前30%
- 帮助其他学习者完成3次挑战
- 接受楚天秋的考核

势力特权：
- 团队挑战资格（最多3人组队）
- 天堂口知识库访问权
- 每日「道」捐赠系统（捐赠者获得声誉）

核心NPC：
- 楚天秋：永远冷静的领袖，实际掌握逃离条件
- 赵庸人：情报收集者，知道很多隐藏信息
- 林檎：话事人，负责新成员引导
```

#### 极道（Extremist Path）
```
加入条件：
- 单次挑战连续胜利5场
- 接受燕知春的意志

势力特权：
- 强制挑战权（可以指定对手）
- 暴力破解副本（消耗「道」直接通关）
- 极道知识库访问权

核心NPC：
- 燕知春：相信力量是唯一出路
- 韩武道：战斗狂人，挑战他获得稀有知识
- 吴明：谋士，提供战术建议
```

#### 貔貅（Fortune Keeper）
```
加入条件：
- 累计获得100「道」
- 购买貔貅股份（消耗50「道」）

势力特权：
- 市场交易折扣
- 情报购买（用「道」换取任何人的信息）
- 貔貅知识库访问权

核心NPC：
- 钱 Meck：精明的商人，任何东西都有价格
- 孙之琼：黑市商人，售卖违禁道具
- 陶净：拍卖师主持特殊活动
```

#### 猫（Hidden Shadow）
```
加入条件：
- 绝对保密，绝不透露「回响」能力
- 完成猫的入会测试（偷取某NPC的信息）

势力特权：
- 隐藏行动（其他势力无法追踪）
- 猫的知识库访问权
- 策反其他势力成员的能力

核心NPC：
- 陈俊南：唯一公开的「回响者」，猫的实际领袖
- 韩片羽：轮回者，掌握时间秘密
- 藏雀：隐形能力者，负责暗杀任务
```

### 3.4 势力互动系统

#### 3.4.1 势力战争
```
触发条件：
- 某势力声望达到100，另一势力不满度达到50
- 或争夺同一知识城池的归属权

战争阶段：
1. 宣战期（第1-3日）：势力公开敌对宣言
2. 对抗期（第4-6日）：完成势力任务会获得对方惩罚
3.决战期（第7-9日）：大型势力战，胜利方获得特权

战争奖励：
- 胜利势力：知识城池税收权 + 专属道具
- 失败势力：成员被迫退出 + 声望大损
```

#### 3.4.2 势力同盟
```
同盟类型：
- 军事同盟：共同挑战天龙
- 经济同盟：共享市场资源
- 秘密同盟：对外敌视，对内合作

同盟任务：
类型1：「联合挑战」
  - 天堂口+猫：潜入天龙领地
  - 天堂口+极道：正面突破
  - 猫+貔貅：情报交易行动

类型2：「势力交换」
  - 临时借调其他势力成员协助
  - 消耗「道」换取其他势力技能
```

#### 3.4.3 背叛与策反
```
背叛条件：
- 完成该势力任务，但获得相反奖励
- 被发现向其他势力透露信息
- 拒绝执行关键任务

策反机制：
- 消耗道具「间谍面具」，伪装加入敌对势力
- 收集3条核心情报后可策反该势力成员
- 被策反者提供势力专属知识库访问权
```

#### 3.4.4 资源争夺
```
争夺目标：
- 知识城池归属（谁挑战谁受益）
- 稀有道具（如「时间暂停」「复活币」）
- 关键NPC（可能被争夺的盟友）
- 隐藏知识库（触发秘密剧情）

争夺方式：
- 竞拍：用「道」最高者获得
- 挑战：击败当前持有者
- 任务：完成特定任务解锁
```

## 四、战斗系统

### 4.1 十二生肖等级

| 等级 | 称号 | 答对要求 | 单次奖励 |
|------|------|---------|---------|
| 人级 | 人鼠/人牛/人虎... | 100% | 10-20「道」 |
| 地级 | 地鼠/地牛/地虎... | ≥80% | 30-50「道」 |
| 天级 | 天鼠/天牛/天虎... | ≥70% | 80-100「道」 |

### 4.2 生肖-知识映射

| 知识领域 | 人级守护者 | 地级守护者 | 天级守护者 |
|---------|----------|----------|----------|
| 编程/技术 | 人鼠（智慧） | 地马（速度） | 天龙 |
| 数学/逻辑 | 人蛇（阴柔） | 地龙（全面） | 天龙 |
| 语言/文字 | 人猴（灵活） | 地鸡（精确） | 天龙 |
| 历史/人文 | 人羊（温顺） | 地猪（厚重） | 天龙 |
| 物理/科学 | 人牛（力量） | 地虎（威猛） | 天龙 |
| 艺术/创意 | 人兔（敏捷） | 地狗（忠诚） | 天龙 |

### 4.3 战斗流程
```
发起挑战 → 对方出题(1-5道) → 答题 → 结算
```

### 4.4 游戏类型

#### 人级游戏
| 游戏名 | 规则 | 难度 |
|--------|------|------|
| 说谎者 | 找出唯一的错误选项 | ★★ |
| 三选一 | 三个选项选正确答案 | ★ |
| 排序 | 按正确顺序排列 | ★★★ |

#### 地级游戏
| 游戏名 | 规则 | 难度 |
|--------|------|------|
| 赌命 | 押上「道」答题，输则失去 | ★★★★ |
| 囚徒困境 | 双人答题，对方错你才能对 | ★★★★ |
| 朔望月 | 日历规则下的答题 | ★★★ |
| 木盒 | 随机抽取题目箱 | ★★★ |

#### 天级游戏
| 游戏名 | 规则 | 难度 |
|--------|------|------|
| 天狗时刻 | 限时答题，时间递减 | ★★★★★ |
| 死亡问答 | 答错即死（经验大损） | ★★★★★ |
| 轮回试炼 | 连续10轮答对进入下一轮 | ★★★★★ |
| 最终面试 | 天龙亲自出题 | ★★★★★ |

## 五、回响系统

### 5.1 回响觉醒条件

| 回响名称 | 觉醒条件 | 效果 |
|---------|---------|------|
| 生生不息 | 连续3次复习同一知识点 | 复习效率+50% |
| 破万法 | 连续解出3道难题 | 难题正确率+30% |
